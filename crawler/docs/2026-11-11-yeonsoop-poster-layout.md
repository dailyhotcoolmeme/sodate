## 변경과 안전 조건

- 한 판독에서라도 명시적인 AM/PM을 읽으면 보정을 재시도한다.
- 보정으로도 일정을 읽지 못하면 원본 이미지를 자동 레이아웃(PSM 3)과
  흩어진 텍스트(PSM 11) 방식으로 각각 읽는다. 로컬 실제 이미지의 두 방식은
  모두 2026-11-21 14:30/언주역을 반환했다.
- 최종 두 결과의 날짜/시각/역이 모두 일치해야 한다. 앞선 판독에서 확정한
  값과 충돌하면 거부한다. 이미지 사이에서 항목을 조합하지 않는다.
- 재시도 판독의 가격은 저장하지 않는다. 무료 로컬 Tesseract만 사용한다.
- 진단 로그는 게시물 ID와 날짜/시각/역의 정규식 결과만 기록한다.
  서명 이미지 URL이나 포스터 본문은 로그에 남기지 않는다.
- `DELETE_STALE=False`, `PRESERVE_MISSING_PRICES=True`와 기존 verified 보호
  저장 경로를 유지한다. 기존 오너 확인 10/31 13:30 일정은 수정하지 않는다.
- 회귀 테스트 203개 통과. 별도 유료 액터 실행 없이 `yeonsoop_replay=true`로
  18시간 이내 기존 정기 수집 자료를 정상 저장 경로에서 재검증한다.
