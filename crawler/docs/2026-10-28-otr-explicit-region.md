# 오프더레코드 원본 지명 반영

- 원본: https://linkfly.to/offtherecord (공개 버튼 JSON, 2026-10-28 확인)
- `11.8(일) 13:00 종로 (얼리버드 할인)`
- `11.8(일) 16:30 종로 (얼리버드 할인)`
- `11.14(토) 14:00 연남동 (얼리버드 할인)`

기존 크롤러가 모든 일정을 종로/을지로로 고정해 연남동 일정도 잘못 노출했다.
버튼의 명시된 지역을 우선하며 연남동은 기존 모델 표준인 연남으로 저장한다.
지명이 없는 예전 형식에만 오너가 확인한 종로/을지로 기본값을 유지한다.
알 수 없는 지명은 저장하지 않고 부분 수집으로 처리해 기존 일정 삭제를 막는다.
날짜·시간·가격과 URL 식별자는 변경하지 않으며 verified=true 보호는 기존 저장 경로를 따른다.

검증: 크롤러 전체 174개 테스트 통과. 실제 원본의 3개 버튼을 저장 없이 파싱해
11/8 13:00·16:30 종로, 11/14 14:00 연남 및 기존 URL 일치를 확인했다.
