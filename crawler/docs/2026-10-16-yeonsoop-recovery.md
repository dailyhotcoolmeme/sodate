# 연숲 이미지 공지 자동 수집 복구

## 원인과 재현

기존 캡션 전용 파서는 오늘 기존 수집 결과 14건에서 과거 8/21 공고만 읽고, 최신 이미지 공지는 읽지 못했다. 따라서 발견 1 / 실제 반영 0이었다. 복구 검증은 유료 액터를 새로 실행하지 않고 완료된 결과를 GET으로만 조회한다.

공식 API: https://docs.apify.com/api/v2/actor-runs-last-dataset-items-get

## 변경

- 기존 정기 Apify 수집 횟수는 하루 2회 그대로다. 받아온 이미지 URL을 무료 로컬 Tesseract `kor+eng`로 읽는다. 외부 AI/OCR API 호출과 AI 토큰 사용은 없다.
- 같은 이미지의 두 레이아웃 인식(`--psm 6`, `--psm 4`)에서 날짜·명시된 시각·역이 일치해야 후보로 만든다. 인식 결과가 다른 가격은 미확인으로 남기고 기존 가격을 보존한다.
- 날짜와 시간은 같은 줄에 있어야 하며 `1:30`만 있는 경우 오전/오후를 추측하지 않는다. 서로 다른 이미지의 날짜/가격을 결합하지 않는다. 날짜·역이 여러 개이면 임의 선택하지 않는다. 참가자 명단으로 나이를 추측하지 않는다.
- `오후 1시 30분`을 13:00으로 읽던 기존 시간 파싱을 13:30으로 수정했다.
- 같은 회차는 합치고 기존 대표 URL과 기존 제목·마감·나이·설명은 보존한다. `verified=true` 행은 기존 보호에 더해 UPDATE 시점에도 `verified=false` 조건을 적용한다. 부분 수집으로 기존 미래 일정을 삭제하지 않는다(`DELETE_STALE=false`).
- 공개 인스타 CDN만 다운로드하며 리다이렉트 금지, 크기/픽셀/시간/건수 상한을 둔다. 동일 이미지 내용은 한 실행 내에서 중복 인식을 피한다. 이미지 축소 시 작은 '원'이 오인식되어 원본 해상도를 유지한다.
- 일반 `crawl.yml` rest 잡에 한국어 Tesseract 설치를 추가했다. 같은 워크플로의 `yeonsoop_replay=true` 검증 분기는 연숲만 기존 자료로 실행한다. 다른 업체 크롤/알림 작업은 실행하지 않는다. `python -m scrapers.yeonsoop --reuse-last-run` 외의 인자는 거절하며, 재사용 자료는 완료 18시간 이내여야 한다.

## 사전 검증

- 전체 테스트 131개 통과. 오전/오후 미정, 날짜/가격 불일치, 다른 이미지 가격 혼합, 과거 일정, 외부/사설망 URL, 오래된 재사용 자료, 기존 마감·나이·대표 주소 보존을 검사했다.
- 공식 10/17 공고 `Dd3M1geEpmd`의 실제 마지막 포스터를 두 방식으로 읽어 `2026-10-17 13:30`, `언주역`, 남녀 공통 `58,000` 일치를 확인했다. 이는 앞서 공식 신청서와 이미지에서 직접 확인한 값과 일치한다.
- 자동 날짜 판독의 10/31 오전/오후는 여전히 원본 확인 전이므로 추측 등록하지 않는다.

## 서버 실행 및 공개 조회 검증 완료

- 수정 커밋 `1cfd0f6`으로 기존 `crawl.yml`의 재사용 검증 `38829852863` 실행 성공. 일반 crawl/post 잡은 skipped임을 확인해 다른 업체 재수집/유료 액터 실행이 없었다.
- 서버 로그: 기존 게시물 14건 → 포스터 공지 중복 3건 합침 → 현재 회차 1건 → 신규 0 / 재확인 1. 실제 `crawl_logs`는 2026-10-16 09:32:29 KST, success, found=1, updated=1, error 없음으로 기록됐다.
- 연숲 DB 총 1행 유지. 기존 ID/대표 주소 그대로이며 10/17 13:30 KST, 남녀 58,000원, 활성/미마감/미검증 상태가 동일하다. 공개 anon 조회 HTTP 200에서도 동일한 일시·가격을 확인했다. 신규 중복이나 기존 행 삭제가 없다.
- 실제 DB를 읽는 `check_empty_crawls()` 결과는 빈 배열로, 연숲의 미재확인·실패 경보가 실제 재확인에 의해 해소됐다. 경보를 끄거나 로그를 임의 수정하지 않았다.
- 10/31 회차의 오전/오후는 원본 확정 전까지 보류하며, 이후 명시된 이미지 공지가 수집되면 같은 판독 경로로 처리한다.
