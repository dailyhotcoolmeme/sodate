# 자동 커뮤니티 게시글 운영 기준

> 2026-09-23 오너와 후배가 샘플을 확인하고 확정한 기준이다.
> 자동 생성기·admin 화면·예약 게시를 수정할 때 이 문서를 먼저 읽는다.

## 목적

- 앱 커뮤니티 홈을 2030 남녀가 읽고 반응할 만한 글로 꾸준히 채운다.
- 글은 매일 10:00부터 다음 날 01:00 직전까지 시간당 2~3개가 자연스럽게 흩어져 올라가게 한다.
- 제목·내용·닉네임은 자동 생성하되, admin에서 수정·게시·삭제할 수 있어야 한다.
- 후배 검토가 끝난 생성 규칙을 통과한 글만 자동 게시한다. admin에서는 언제든 수정·제외·삭제할 수 있다.

## 확정된 말투

기존 게시판 실데이터를 확인한 결과 다음 말투가 정본이다.

- 정리된 상담글·블로그 문체를 쓰지 않는다.
- 짧게 끊고 실제 익명 게시판처럼 말한다.
- `ㅇㅇ`, `ㅋㅋ`, `ㅋㅋㅋ`, `??`, `ㄱㅊ?`, `추천좀`, `어떰?` 등을 문맥에 맞게 쓴다.
- `:)`, `ㅠ`, `ㅜ`, `ㅎㅎ`, 마침표는 쓰지 않는다.
- 모든 글에 초성·이모티콘을 억지로 넣지 않는다.
- 맞춤법을 지나치게 다듬지 않되, 읽기 어려운 수준으로 일부러 망가뜨리지 않는다.
- 제목에서 상황을 바로 알 수 있게 하고, 본문 끝에는 짧게 반응을 묻는 경우가 많다.
- 같은 문장 구조와 말끝을 연속해서 쓰지 않는다.
- 2~6문장 정도를 기본으로 하되 한 줄짜리 가벼운 글도 섞는다.

### 승인된 샘플

제목:

> 소개팅 잘되면 여자쪽에서 먼저 2차 말해도 ㄱㅊ?

내용:

> 소개팅 상대랑 연락할때 느낌은 괜찮거든??
>
> 카페에서 얘기 잘통하면 내가 먼저 밥먹자고 해볼까 하는데  
> 너무 맘에들어하는 티나는건가 ㅋㅋ
>
> 남자들 입장에서 여자가 먼저 2차가자하면 어떰?  
> 걍 배 안고프냐고 물어보면 되나 ㅋㅋ

## 소재 비율

- 소개팅·첫 만남·애프터 고민 35%
- 썸·연애·연락 문제 25%
- 로테이션 소개팅·소셜링 경험과 질문 20%
- 직장·주말·데이트·맛집 등 2030 일상 15%
- 가벼운 밸런스게임·유행 소재 5%

## 글 유형·말머리 배합

- 3건을 한 묶음으로 만들 때 후기 성격의 글 1건을 반드시 넣는다. 후기라고 해서 말머리를 반드시 붙이지는 않는다.
- 나머지 2건은 `고민상담/궁금해요` 1건과 `일상 잡담/동행구함` 1건으로 나눈다. 동행 모집이 너무 많아지지 않게 다섯 묶음 중 한 묶음만 동행으로 한다.
- 60건 기준은 후기 20건·고민 10건·궁금 10건·일상 16건·동행 4건으로 고정한다.
- 전체 초안의 소재를 먼저 배정해, 같은 `로소 첫 후기`나 비슷한 질문이 연속 생성되지 않게 한다.
- 후기글은 질문형으로 끝내지 않고, 직접 겪은 느낌·소감으로 자연스럽게 끝낸다.
- **말머리 없는 글이 훨씬 많아야 한다.** 전체 생성 글 중 말머리는 약 15~25%만 사용하고 최소 75%는 말머리 없이 둔다.
- 말머리는 글 내용과 맞을 때만 붙이며, 내용이 후기·고민·질문이어도 대부분 생략한다.
  - 후기 → `[리얼후기]`
  - 조언을 구하는 고민 → `[고민상담]`
  - 가벼운 질문 → `[궁금해요]`
  - 동행 모집 → `[동행구함]`
  - 일상 잡담 → 말머리 없음

## 본문 길이 배합

- 전체의 약 80%는 익명 게시판에서 빠르게 읽는 2~6문장 글로 만든다.
- 약 5건 중 1건은 상황과 생각이 이어지는 6~9문장, 160자 이상 글로 만든다.
- 긴 글은 짧은 문장을 반복해 늘리지 않고 사건의 흐름·헷갈리는 지점·느낀 점이 이어져야 한다.
- 긴 글도 블로그나 상담문처럼 소제목으로 정리하지 않고 실제 사용자가 사정을 조금 자세히 적은 말투를 유지한다.
- 긴 글이 서로 연속해서 올라가지 않도록 생성 순서에서 흩어 놓는다.

## 생성 금지

- 실제 사람·업체에 대한 확인되지 않은 폭로·비방
- 실명, 연락처, 카카오톡 아이디 등 개인정보
- 성매매·불법·투자 유도·의료 조언
- 기존 게시글이나 외부 글의 문장 복사
- 특정 이용자 글에 답하는 것처럼 꾸미는 내용
- 이미 최근 30일 안에 다룬 제목·상황과 사실상 같은 글
- 오늘·내일·지금·요일·주말·아침·점심·퇴근·저녁·밤·새벽 등 게시 시각과 어긋날 수 있는 표현
- 비·눈·날씨·기온·더위·추위·계절 등 실제 날씨와 어긋날 수 있는 표현
- 소개팅·로소·소셜링·혼술바 이용 경험이 아닌데 `[리얼후기]`를 붙인 글

## 닉네임

- 게시물마다 2~12자의 임의 닉네임을 배정한다.
- 앱 최초 진입 시 배정되는 `형용사+동물·음식·사물+2자리 숫자`형(예: `느긋한붕어빵42`)과 짧은 익명형을 1:1로 섞는다.
- 짧은 익명형은 `ㅇㅇ`, `ㅋㅋ`, `궁금`, `퇴근하고싶다`, `주말뭐하지` 같은 기존 스타일을 쓴다.
- 같은 닉네임을 연속으로 쓰지 않고, 한 생성 묶음에서 한 닉네임은 최대 2번만 쓴다.
- 금칙어·업체명·실명처럼 보이는 이름은 쓰지 않는다.

## 프로필 이미지

- 앱에 내장된 실제 프로필 이미지 24종(`thumbs_01`~`thumbs_24`)에서 게시물마다 하나를 랜덤 배정한다.
- 배정된 이미지 번호를 초안에 저장해, 게시 후에도 같은 이미지가 계속 보이게 한다.
- 실제 예약 게시 순서를 기준으로 24종을 매일 다시 무작위로 섞는다.
- 같은 이미지가 연속해 나오지 않게 하고, 24종을 다 쓰기 전에는 중복되지 않게 한다.

## 게시 흐름

1. 정기 실행은 현재 유료 플랜의 Cloudflare Workers AI로 새 글을 만들고, 로컬 고정 본문은 수동 비상 생성에만 사용한다.
2. 과거 공개·대기 글 전체와 제목·본문을 비교해 동일하거나 유사한 글은 버린다.
3. 생성·말투·시간·날씨·말머리 검사를 통과한 결과를 `auto_board_posts`에 `ready`로 저장한다.
4. 매일 09:40 KST에 10:00~다음 날 01:00 게시 시각을 배정한다.
5. 시간당 2건 또는 3건을 임의로 고르고 정각에 몰리지 않게 분산하며, 초는 `00~59` 사이에서 게시글마다 무작위로 정한다.
6. 예약 시각이 되면 `board_posts`에 복사되고 앱 커뮤니티 홈 최신순에 노출된다.
7. 게시 후에도 admin 자동 게시 관리에서 내용 수정·숨김·삭제가 가능해야 한다.

## 토큰 사용 원칙

- 매일 05:10 KST 자동 보충은 유료 플랜에 포함된 Cloudflare Workers AI만 사용한다.
- 예약·게시·프로필 이미지 배정은 전부 DB에서 처리하므로 AI 토큰을 사용하지 않는다.
- 다른 AI 공급자는 사용하지 않는다.
- `CF_WORKERS_AI_TOKEN`은 정기 생성 작업과 오너가 수동으로 Cloudflare 생성을 선택한 작업에만 주입한다.
- AI 생성 결과에는 `cloudflare-workers-ai:<모델명>`을 기록해 어떤 공급자와 모델을 썼는지 admin과 DB에서 확인할 수 있게 한다.
- 로컬 조합도 AI 결과와 같은 금칙어·시간·날씨·말투·말머리 검사를 통과해야 저장된다.
- 제목이 달라도 본문이 같거나 문장 일부만 바꾼 유사 글이면 저장하지 않는다.
- 검사를 통과한 새 글이 부족하면 반복 글을 억지로 채우지 않는다.

## 자동 게시 전환 조건

- `auto_publish_enabled=true`일 때만 예약과 공개를 실행한다.
- 운영 시간은 10:00 이상, 다음 날 01:00 미만이다.
- 시간당 2~3개를 정각에 몰지 않고 임의 분으로 나눈다.
- 검사를 통과한 대기 글을 90건 유지해 최대 게시량 기준 이틀치 여유를 둔다.
- 이전 시간대의 밀린 글은 운영 시간 밖에 몰아서 올리지 않는다.
- 대기 글 부족·게시 실패 시 억지로 빈 글을 올리지 않고 admin에 상태를 남긴다.
