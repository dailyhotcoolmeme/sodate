# 익명 게시판(심야톡) 사양

> 2026-07-29 오너 확정 사항. 미확정 항목은 "열린 항목"에 모아둔다.

## 개요
톱바에 메뉴 탭 하나 추가. 회원가입 없이 글·댓글 작성, 좋아요, 이미지 첨부.
좋아요가 많은 글은 목록에서 진하게 표시. 글 누르면 상세 보기.

## 확정된 결정

| 항목 | 결정 | 이유 |
|---|---|---|
| 도입 시점 | **승인·오픈 후 별도 업데이트** | 지금 넣으면 심사 재제출 + 리젝 위험. 오픈 직후엔 글이 없어 빈 게시판이 오히려 역효과 |
| 게시판 성격 | **자유 주제 심야톡** | 오너 결정 |
| 작성자 식별 | **기기 토큰(owner_token)** — 후기 기능과 동일 | 회원가입 없이 본인 글 삭제·차단 대상 지정 |
| 악성 사용자 차단 | **관리자가 기기 토큰 차단** | Apple 가이드라인 1.2 필수 요건 |
| 게시 방식 | **글은 즉시 게시 / 이미지 붙은 글만 승인 후 이미지 노출** | 사고는 대부분 이미지에서 남. 부담 대비 효과가 큼 |
| 승인 알림 | **admin 배지 표시만** | 오너 결정 |

## 재사용할 기존 자산

- `owner_token` — 후기에서 이미 쓰는 익명 소유권 토큰
- `ReportSheet` / `report_count` — 신고 UI·집계
- admin `Reviews.tsx` — 검수 화면 패턴
- R2(`sodate-media`) + `/api/upload` — 이미지 저장
- `ReviewSheet` — 작성 시트 UI 패턴

## 스토어 심사 요건 (Apple 1.2 사용자 생성 콘텐츠)

1. 부적절한 콘텐츠 필터링 → 금칙어 필터 + 이미지 사전 승인
2. 신고 기능 → 기존 ReportSheet 확장
3. 악성 사용자 차단 → 기기 토큰 차단 (신규)
4. 게시된 연락처 → 이미 있음(admin@ourmine.co.kr)
5. **신고 후 24시간 내 삭제 및 차단** → 운영 약속

⚠️ UGC 추가로 연령 등급 재평가 대상이 될 수 있다.

## 알려진 위험

- **자유 주제 + 익명 + 소개팅 앱** 조합은 음란물·홍보·비방이 반드시 들어온다.
  금칙어 필터를 처음부터 촘촘히 넣지 않으면 며칠 만에 감당이 안 된다.
- 승인 알림이 admin 배지뿐이라, 오너가 admin을 안 열면 이미지가 계속 안 보이고
  24시간 대응 요건도 못 맞춘다. 운영하면서 푸시 알림 필요 여부를 재검토할 것.

## 열린 항목 (미확정)

- 좋아요 중복 방지 방식과 "진하게" 표시 기준(몇 개부터?)
- 이미지 첨부 개수 제한
- 글 삭제용 비밀번호를 별도로 둘지(기기 토큰만으로 충분한지)
- 목록 정렬(최신순/인기순) 및 기본값
- 신고 N건 누적 시 자동 숨김 임계치
- 금칙어 목록 초안
- 오래된 글 보관 기간
