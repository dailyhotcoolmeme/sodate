# 바텀내비 아이콘 제작 의뢰문 (소밋 · 5개)

> 외부(다른 AI/디자이너)에 그대로 붙여넣어 쓰는 지시문.
> ①공통 규격을 먼저 주고, ②아이콘 5개를 하나씩 요청한다.

---

## ① 공통 규격 (먼저 이것부터 붙여넣기)

```
한국 모바일 앱 '소밋'의 하단 탭바 아이콘 5개를 만들려고 합니다.
아래 규격을 모두 지켜서 SVG 코드로 주세요.

[서비스]
- 20~30대 남녀가 쓰는 오프라인 만남 앱. 소개팅 모임·취미 모임·혼술 술집 정보·커뮤니티를 한곳에 모아 보여줍니다.
- 브랜드 색은 핑크(#FF6B9D), 로고는 선으로 그린 하트입니다.

[기술 규격]
- viewBox="0 0 24 24", 그림은 20x20 안에 담고 상하좌우 2씩 여백을 둡니다.
- 2톤 구조: '면(fill)'과 '선(stroke)'을 분리해 주세요. 앱에서 색을 바꿔 끼웁니다.
  · 면은 반드시 #CCCCCC 한 색으로만
  · 선은 반드시 #111111 한 색으로만
  · 그 외 색·그라디언트·그림자·투명도·텍스처 금지
- 선 굵기 1.5 고정(모든 아이콘 동일), stroke-linecap="round", stroke-linejoin="round"
- 면은 닫힌 path로 채우고, 반투명 겹침으로 색을 만들지 마세요.
- <path> 개수는 아이콘당 6개 이하. <text>·<image>·<filter>·<mask> 사용 금지.

[디자인 규격]
- 32px로 줄여도 형태가 읽혀야 합니다. 얇은 디테일·작은 구멍·1px 장식 금지.
- 5개가 나란히 놓입니다. 시각적 무게와 크기감을 서로 맞춰 주세요
  (한 개만 굵거나 크게 보이면 안 됩니다).
- 기하학적이고 둥근 형태. 각진 모서리보다 부드러운 곡선.
- 선택/비선택은 앱이 색으로만 구분합니다. 채워진 버전/빈 버전을 따로 만들지 마세요.

[피할 것]
- 원형·사각형 배경으로 감싸지 마세요. 아이콘 자체만 필요합니다.
- 글자·숫자·이모지풍·3D·입체 그림자·스큐어모픽 금지.
- Lucide, Feather, Material 기본 아이콘을 그대로 옮긴 듯한 흔한 형태 금지.
  (이전에 그런 형태를 써봤다가 "촌스럽고 AI가 만든 티 난다"는 평가를 받았습니다.)
```

## ② 아이콘별 요청문

### 1. 소개팅 (첫 번째 탭)

```
1번 아이콘 '소개팅'입니다.
전국 로테이션 소개팅 모임 일정을 모아 보여주는 메뉴입니다.
- 핵심 개념: 처음 만나는 남녀, 마주 앉음, 설렘
- 1안: 마주 본 두 사람의 상반신 실루엣(얼굴은 단순한 원, 사이에 작은 하트나 여백)
- 2안: 두 개의 하트가 살짝 겹친 형태
- 3안: 테이블을 사이에 둔 두 사람
⚠️ 앱 로고가 이미 '선으로 그린 하트'라 하트만 단독으로 쓰면 로고와 겹칩니다.
   하트를 쓰더라도 로고와 구분되게 변형해 주세요.
세 안 모두 SVG로 주세요.
```

### 2. 소셜링 (두 번째 탭)

```
2번 아이콘 '소셜링'입니다.
취미·관심사로 여러 명이 모이는 모임(독서, 와인, 러닝 등)을 보여주는 메뉴입니다.
- 핵심 개념: 여럿, 무리, 함께
- 1안: 사람 3명이 모여 있는 형태(앞 1명 + 뒤 2명, 크기 차이로 원근)
- 2안: 원 세 개가 삼각형으로 모인 추상 형태
- 1번(소개팅) 아이콘과 확실히 구별돼야 합니다.
  소개팅=둘이 마주 봄 / 소셜링=여럿이 모임 이 대비가 한눈에 보여야 합니다.
두 안 모두 SVG로 주세요.
```

### 3. 커뮤니티 (가운데 탭 — 가장 중요)

```
3번 아이콘 '커뮤니티'입니다. 탭바 한가운데에 놓이고, 다른 것보다 크게(52px)
그려져 탭바 윗선 위로 살짝 튀어나옵니다. 이 앱에서 매일 들어오는 중심 메뉴입니다.
- 핵심 개념: 이야기, 수다, 익명 게시판
- 1안: 말풍선 하나(안에 점 세 개 대신, 더 개성 있는 처리)
- 2안: 말풍선 두 개가 겹친 형태(대화)
- 다른 4개보다 크게 그려지므로 형태가 조금 더 풍성해도 됩니다.
  다만 52px에서 좋아 보이면서 32px에서도 안 뭉개져야 합니다.
- 배경 원으로 감싸지 마세요. 아이콘 자체가 강조되는 형태여야 합니다.
두 안 모두 SVG로 주세요.
```

### 4. 혼술바 (네 번째 탭)

```
4번 아이콘 '혼술바'입니다.
혼자 술 마시기 좋은 바·이자카야를 지도와 목록으로 보여주는 메뉴입니다.
- 핵심 개념: 혼자 한 잔, 바(bar), 밤
- 1안: 칵테일 잔(삼각형 잔) 하나 — 단, 흔한 마티니 잔 클립아트처럼 보이지 않게
- 2안: 하이볼 잔(길쭉한 원통) + 얼음
- 3안: 잔 하나 + 작은 달/별 하나(밤 뉘앙스)
- '여럿이 건배'가 아니라 '한 잔'이어야 합니다. 잔은 하나만.
세 안 모두 SVG로 주세요.
```

### 5. MY (다섯 번째 탭)

```
5번 아이콘 'MY'입니다. 내 정보·스크랩·내가 쓴 글이 모인 메뉴입니다.
- 핵심 개념: 나
- 1안: 사람 상반신(머리 원 + 어깨 곡선)
- 2안: 사람 상반신이 둥근 테두리 안에 든 형태
- 가장 흔한 아이콘이라 오히려 특징이 필요합니다.
  나머지 4개와 같은 조형 언어(같은 곡률·같은 굵기)로 통일해 주세요.
두 안 모두 SVG로 주세요.
```

## ③ 받은 뒤 확인할 것 (내가 검수)

- [ ] 5개를 32px로 나란히 놓고 봤을 때 크기·무게가 고르게 보이는가
- [ ] 가운데(커뮤니티)만 52px로 키웠을 때 어색하지 않은가
- [ ] 색이 정확히 `#CCCCCC`(면)와 `#111111`(선) 두 개뿐인가 → 앱 색으로 치환 가능
- [ ] 선 굵기가 5개 모두 1.5로 같은가
- [ ] 다크모드에서 뒤집었을 때 면색이 덩어리로 뜨지 않는가
- [ ] 상업적 이용·수정이 가능한 결과물인가(출처표기 의무가 있으면 어디에 적어야 하는지)

## ④ 참고 — 지금 적용돼 있는 값

| 항목 | 값 |
|---|---|
| 일반 아이콘 크기 | 32px |
| 가운데(커뮤니티) | 52px, 바 윗선 위로 8px 돌출 |
| 탭바 높이 | 56px |
| 선택 시 | 선 `#FF6B9D` / 면 `#FFD9E6` (다크: 면 `#5A2A3C`) |
| 비선택 시 | 선 `#999999`(다크 `#606060`) / 면 `#E9E9F0` (다크 `#2A2A31`) |

받은 SVG는 내가 `app/components/TabIcons.tsx` 의 React Native 컴포넌트로 바꿔 넣는다
(색은 `stroke`/`fill` prop 으로 치환).
