# 모잇 인스타 카드뉴스 — 그록 지시서 (6장)

레퍼런스는 `haninin__` 의 '오늘관리' 카드뉴스 5장이다. 각 장을 만들 때 **레퍼런스 1장 + 앱
화면 1장**을 함께 첨부하고, 아래 지시문을 그대로 붙여넣는다. 한 장씩 따로 만든다.

**레퍼런스 부르는 이름** (화면 오른쪽 위 번호로 구분)

| 이름 | 어떤 장면인가 |
|---|---|
| 레퍼런스 ① | `01/05` — 지도 위에 큰 제목이 얹힌 표지 |
| 레퍼런스 ② | `02/5` — 위에 제목, 아래에 폰 목록 화면이 크게 |
| 레퍼런스 ③ | `03/5` — 위에 제목, 아래에 필터 카드 |
| 레퍼런스 ④ | `04/5` — 위에 제목, 아래에 상세 정보 카드 |
| 레퍼런스 ⑤ | `5/5` — 앱 아이콘과 큰 제목, 아래에 버튼 |

**공통 준비물**

- 캔버스는 **1080 × 1080 정사각형**으로 만들게 한다. (그록은 4:5를 제대로 못 만든다)
- 앱 화면 이미지는 **다시 그리지 말고 그대로 쓰라**고 못 박는다. 글씨를 새로 그리면
  없는 기능이 있는 것처럼 보인다.
- 카피 문구는 **오너 확정본이라 한 글자도 바꾸지 말라**고 못 박는다.
- 색·배치·글꼴·분위기는 지시하지 않는다. 레퍼런스를 보고 그록이 정한다.

## 1장 — 표지

**첨부:** 레퍼런스 ① / (앱 화면 없음)

```
첨부한 이미지는 참고용 레퍼런스다. 이것과 같은 결의 인스타그램 카드뉴스 표지 1장을 만들어라.

[배경 이야기]
'모잇'은 한국의 앱이다. 로테이션 소개팅, 소셜링 모임, 혼술바 정보가 네이버·인스타·여러
플랫폼에 흩어져 있어서, 주말에 뭘 할지 찾다가 시간만 버리는 일이 많다. 그게 답답했던
개발자가 흩어진 정보를 한곳에 모아주는 앱을 직접 만들었다. 이 카드뉴스는 그 앱을 알리는
인스타그램 게시물의 첫 장이다.

[보는 사람]
주말에 새로운 사람을 만나고 싶은 20~30대 한국인.

[반드시 지킬 것]
- 캔버스는 1080 x 1080 정사각형.
- 배경은 훈남훈녀가 소개팅하는 분위기의 사진으로 만들어라.
- 아래 문구를 한 글자도 바꾸지 말고 그대로 넣어라. 새로 쓰거나 다듬지 마라.
  메인 카피: 개발자가 답답해서 직접 만든 "소개팅/소셜링/혼술바 모아보기" 앱
  서브 카피: 주말에 뭐할지 고민 끝. 새로운 사람 만나는 가장 쉬운 방법, 모잇
- 상표나 다른 회사 로고는 넣지 마라.

색·글꼴·배치·분위기는 레퍼런스를 참고해 네가 정해라.
```
