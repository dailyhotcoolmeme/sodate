⚠️ **GitHub Actions 의 schedule 은 원래 잘 밀린다**(요금제와 무관, 공식 문서에도 적혀 있다).

## 3. 반드시 지켜야 할 것들 (사고로 배운 것)

### 3-1. `verified` 는 절대 건드리지 않는다

오너가 admin 에서 손으로 고친 값은 `events.verified=true` 가 된다.
지난 일정 정리·스테일 삭제 **둘 다 `verified=false` 인 것만** 만진다.
파트너가 포털에서 직접 등록한 일정도 `verified=true` + `is_partner_direct=true` 로 들어간다
— 그래서 크롤러가 지우지 않는다.

### 3-2. 스테일 삭제의 안전판

`base_scraper.py` 는 "이번 크롤에 없는 기존 일정"을 지운다. 그런데 사이트가 잠깐 죽어
절반만 긁어오면 멀쩡한 일정이 날아간다. 그래서 **기존 대비 재확인율이 50% 미만이면
삭제를 건너뛴다.** 이 안전판을 없애지 말 것.

### 3-3. `networkidle` 을 무방비로 쓰지 않는다 🚨

`wait_for_load_state('networkidle')` 은 «네트워크가 조용해졌나»일 뿐 **화면이 그려졌나가 아니다.**
광고·채팅 위젯이 요청을 물고 있으면 영영 안 끝난다. 그런데 시간초과가 나도 화면은 대개 다 그려져 있다.

| 어디서 터지나 | 결과 |
|---|---|
| 목록 페이지 | 예외가 위로 튀어 **크롤 전체가 죽고 0건** |
| 항목(상품) 페이지 | **그 항목만 조용히 건너뛴다** |

항목마다 담긴 일정 수가 제각각이라(에모셔널오렌지는 1~33건) **큰 항목 하나만 놓쳐도
33건이 사라진다.** 실제로 299건이 144건으로 떨어졌고, 워치독이 이걸 '급락'으로 잡아
오탐 메일을 계속 보냈다(2026-09-05).

**규칙**
1. `networkidle` 대기는 **언제나 try 로 감싸고 못 기다려도 그냥 진행**한다
2. 항목 열기(`goto`) 실패는 **한 번 재시도**한다
3. **몇 개를 못 가져왔는지 반드시 로그에 남긴다** — 조용히 빠지면 건수가 줄어도
   사이트가 바뀐 건지 몇 개 놓친 건지 구분할 수 없다

`domcontentloaded` 는 HTML만 읽으면 끝나 거의 안 터진다. 거기서 실패했다면 정말로 페이지가
안 온 것이므로 **그냥 진행하면 오히려 조용히 0건**이 된다 — 그건 감싸지 않는다.

> **건수와 소요 시간이 정비례하면 이 증상을 의심하라.** 파싱이 깨진 거라면 시간은 그대로인데
> 건수만 준다. 시간까지 짧아졌다면 «중간에 건너뛰고 있다»는 뜻이다.

고친 파일: `emotional_orange.py` · `lovecommunity.py` · `lovecasting.py` · `yeongyul.py`
아직 안 고친 곳: `seolrem.py` · `twoyeonsi.py` · `modparty.py` (이들은 `domcontentloaded` 라 위험이 낮다)

### 3-4. 바뀐 값만 쓴다 🚨 (전송량 사고)

2026-09-04, 크롤러가 **안 바뀐 값까지 매번 다시 쓰는** 버그로 Supabase 무료 전송량이
소진돼 **출시된 앱이 멈췄다.** 새 프로젝트로 옮겨 복구했다.
→ 저장 경로 **전부**에 "바뀐 값만 쓰기"를 빠짐없이 적용할 것. 한 군데만 빠져도 다시 터진다.

### 3-5. 중복제거 키에 가격을 반드시 넣는다

프립에서 중복제거 키가 «지역+시간»만 봐서 **별개 일정을 조용히 지우던** 사고가 있었다
(2026-07-25). 같은 시간·같은 지역이어도 가격이 다르면 다른 일정이다.

### 3-6. 지역값 대조할 때의 함정

`models/event.py` 의 `normalize_region` 이 값을 바꾼다(마포→홍대 등).
크롤러 함수만 불러서 사이트와 대조하면 **대량 오진**이 난다. 반드시 모델을 거친 뒤 비교할 것.

## 4. 나이 표기 규칙 (앱과 맞물려 있음)

- **출생연도(년생)는 앱에 절대 쓰지 않는다.** 항상 만나이.
- **만나이 = 올해 − 출생연도.** `+1` 을 붙이면 세는나이가 되어 한 살씩 어긋난다
  (2026-09-07 실제로 그렇게 내서 오너 검수표와 전부 어긋났다).
- 앱은 `NN` 또는 `NN~NN` 일 때만 뒤에 «세»를 붙인다. 그 밖에는 받은 글자를 **그대로** 그린다.
  → 한쪽 경계만 있을 땐 `35~` 가 아니라 **`35세 이상`**, `~37` 이 아니라 **`37세 이하`** 로 보낼 것.
- `age_range_min` / `age_range_max` 도 같이 채워야 앱 나이 필터가 걸린다.

### 에모셔널오렌지 — 2026-09 사이트 개편 (중요)

옛 imweb 쇼핑몰 → 자체 사이트로 갈아탔다. 옛 주소는 **404** 가 됐다.

**새 사이트에서 받는 법** (`scrapers/emotional_orange_new.py`):
화면 주소 뒤에 `.data` 를 붙이면 화면이 쓰는 자료를 그대로 준다.

```
목록  https://emotional0ranges.com/meetups.data          → 모임 34개
상세  https://emotional0ranges.com/meetups/{id}.data     → 날짜별 일정
```

- 브라우저를 안 띄운다 → **2초**(예전 300초), 282건(예전 253건)
- 성별 가격·정원·**잔여석**·나이가 숫자로 그대로 온다
- 형식이 «turbo-stream» 이라 값들이 서로를 번호로 가리킨다. `resolve()` 로 한 번 풀어야 한다
- **없는 값은 null 이 아니라 `-5` 같은 음수로 온다** → 반드시 `_num()` 으로 거를 것

`scrape()` 는 새 사이트를 먼저 보고, 0건이면 옛 imweb(`emotional0ranges1.imweb.me`)으로 넘어간다.

⚠️ **`source_url` 을 바꾸면 기존 일정이 전부 새 것으로 잡혀 중복이 쌓인다.**
주소 체계를 옮길 땐 DB의 기존 `source_url` 도 같이 바꿔주거나, 새로 넣고 옛것을 지워야 한다.

⚠️ **업체에 "사이트 언제 바꾸냐"고 묻지 말 것.** 우리가 크롤링한다는 걸 알려주는 꼴이다.

## 6. 워치독 (`crawler/watchdog.py`)

20분마다 돌며 두 종류 메일을 보낸다.

| 메일 | 뜻 |
|---|---|
| 🚨 긴급 | 지금 손봐야 한다. 그동안 옛 일정이 앱에 그대로 노출된다 |
| 📋 운영 과제 요약 | 급하지 않다. 하루 한 번만 |

### '며칠째 방치' 계산 규칙 🚨

**지속 기간을 알림 이력으로 세면 안 된다.** 두 번 틀렸다.

- 지문(fingerprint)은 `company + msg` 인데 **msg 에서 숫자를 뺀 뒤** 만든다.
  그래서 `173건` 이든 `144건` 이든 **같은 지문**이다.
- 널뛰는 업체는 몇 시간마다 같은 지문이 다시 떠서 24시간 공백이 안 생긴다
  → `first_seen_at` 이 영영 리셋되지 않아 «11일째 방치» 가 됐다.

**규칙**: 문제의 지속 기간은 언제나 **실제 데이터**(크롤 기록 시각)에서 계산해
`issue['persisted_days']` 로 실어 보낸다. 그 값이 있으면 그쪽이 정본이다.

**한 번 튄 값으로 긴급 알림을 보내지 않는다.** 건수는 업체에 따라 원래 들쭉날쭉하다
→ `DRIFT_LOW_RUNS = 3`, 최근 성공 크롤이 **연속 3회** 기준 미만일 때만 급락으로 본다.

## 7. 고칠 때 이렇게 검증한다

1. **DB에 쓰지 말고 `scrape()` 만 부른다** (`run()` 은 저장까지 한다)
2. 사이트가 준 원본 값과 DB에 저장된 값을 **전 건 대조**한다
   - 시각은 DB가 세계표준시라 **한국시간으로 맞춰서** 비교할 것 (안 그러면 9시간 차이로 전부 불일치로 보인다)
3. `networkidle` 관련 수정은 **몽키패치로 항상 실패하게 만들어** 그래도 건수가 나오는지 본다
4. 나이는 **오너 검수표와 대조**해 검산한다

```python
# 예: 시간초과를 강제로 내서 고친 게 진짜 듣는지 본다
import playwright.sync_api as psa
orig = psa.Page.wait_for_load_state
def always_fail(self, state=None, **kw):
    if state == 'networkidle':
        raise psa.TimeoutError('강제 시간초과(시험용)')
    return orig(self, state, **kw)
psa.Page.wait_for_load_state = always_fail
```

크롤러는 `crawler/.venv` 를 쓴다. `.venv/bin/python` 으로 실행할 것.
`crawler/.env` 에 접속 정보가 있다.
