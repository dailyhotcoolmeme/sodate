# sodate 스토어 제출 가이드 (2026-07-11)

> 연령등급 방침(오너 확정): **콘텐츠 기준 등급**. 청소년이용불가(=성인 본인인증 강제)로 가지 않는다.
> 무회원 설계 유지. 약관의 "만 19세 이상"은 정책 문구로, 스토어 콘텐츠 등급과 별개.

## 1. 연령등급 (설문 정직하게 답변 → 성인인증 회피)
- **App Store**: 연령등급 17+ 예상. 앱 내 웹브라우저 없음(아웃링크는 외부 브라우저=`Linking.openURL`) → "제한 없는 웹 접근" **아니요**. 노골적/성적 콘텐츠 **없음**. 소개팅 정보 성격상 17+로 수렴. **17+는 라벨일 뿐 본인인증 불필요.**
- **Google Play (IARC 설문)**: 앱 내 성적/폭력 콘텐츠 **없음**, 이용자 간 매칭·채팅 기능 **없음**(정보+아웃링크만), UGC(후기)는 **신고·자동필터·24h 모더레이션 있음**으로 답변 → **만 12~15세**로 수렴 예상. **청소년이용불가로 억지 상향 금지**(성인 본인인증 강제됨).

## 2. 데이터 보안/개인정보 라벨 (개인정보처리방침 기준)
수집 항목(둘 다 콘솔에 동일 신고):
- 기기 식별자(푸시 토큰), 앱 사용/설정(관심지역·테마·알림), 후기(닉네임·내용·별점), **광고 식별자(광고ID/IDFA)**, 진단(기기모델·OS·앱버전).
- 계정/실명/연락처 **미수집**. 데이터 **판매 없음**. 광고ID는 광고목적.
- 3자: Google AdMob(광고), Supabase(미국 서버·저장). 개인정보처리방침 URL 필수(아래).

## 3. 스토어 리스팅 메타데이터
- 앱 이름: **소개팅모아** / 부제(App Store subtitle): 예) "전국 로테이션 소개팅 일정 모아보기"
- 카테고리: **라이프스타일** 또는 소셜(데이팅 카테고리는 정책 엄격 → 라이프스타일 권장)
- 개인정보처리방침 URL: **https://ourmine.co.kr/sodate/privacy**
- 지원/문의: contact@ourmine.co.kr (또는 지원 URL)
- **개발자 웹사이트: https://ourmine.co.kr** ← app-ads.txt(`/app-ads.txt`)를 구글이 찾으려면 필수
- 스크린샷: iPhone 6.7"/6.5", iPad(미지원이면 불필요), Android 폰. 5~8장(피드·상세·필터·후기 등).
- 설명/키워드: 정보 중개(각 업체 신청은 아웃링크) 성격 명시.

## 4. 남은 실제 작업 (순서)
1. **개인정보 URL 게시** ✅ 완료(ourmine.co.kr/sodate/privacy·terms)
2. **app-ads.txt** ✅ 완료(ourmine.co.kr/app-ads.txt) → 리스팅 "개발자 웹사이트"를 ourmine.co.kr로
3. **새 앱 아이콘** 확정(오너) → app.json icon/adaptiveIcon/splash 교체
4. **production 빌드** `eas build --profile production`(iOS·Android) — 실광고·아이콘·스플래시 반영
5. **AdMob**: 결제 프로필(수익 은행계좌)+세금정보 등록 / 게시 후 앱 스토어연결(verify)
6. **스토어 등록·제출**: App Store Connect / Play Console 앱 생성, 위 메타데이터·등급설문·데이터보안 입력 → 심사 제출
7. (선택) iOS ATT는 재빌드 때 추가 시 개인화광고 가능(없어도 광고 노출)

## 참고: 등급과 약관의 관계
"만 19세 이상 이용"(약관)은 서비스 정책이고, 스토어 콘텐츠 등급(12~17+)은 앱 콘텐츠 기준이라 **서로 모순 아님**. 성인 타겟이라도 앱 콘텐츠가 benign하면 청소년이용불가로 갈 필요 없음(오히려 본인인증 강제로 무회원 설계가 깨짐).
