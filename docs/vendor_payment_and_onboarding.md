# 업체는 신청·결제를 어떻게 받나 — 그리고 우리가 직접 등록 기능을 만든다면

관리하나? 홈페이지 없는 업체는 결제를 어떻게 받나?")에서 출발했다.

## 1. 장터형 플랫폼(문토·프립)은 어떻게 돌아가나

**등록은 공짜다. 대신 참가비에서 수수료를 뗀다.**

| | 등록비 | 수수료 | 정산 |
|---|---|---|---|
| 문토 | 없음 | **참가비의 20%** (카드 수수료·부가세 포함) | 모임 종료 다음 주 수요일에 80% 입금 |
| 프립 | 없음 | **9.9%** (2022-03 반값 인하, 결제 수수료·부가세 포함) | 매주 수요일 입금 |

- 참가자가 **플랫폼 앱 안에서 결제**한다. 돈은 플랫폼이 먼저 받아두고, 모임이 끝난 뒤
  수수료를 뗀 나머지를 호스트에게 보낸다. 3만원 × 10명이면 문토는 24만원, 프립은 27만원.
- 그 수수료 안에 카드 결제 수수료와 부가세가 포함돼 있다. 호스트는 결제 시스템을 따로
  붙일 필요가 없고 환불 처리도 플랫폼이 한다.
- 프립은 성과 좋은 '슈퍼호스트'에게 수수료를 추가로 깎아준다.

**권한은 업체가 직접 관리한다.** 둘 다 호스트 전용 관리자 화면이 따로 있다. 프립은
호스트 어드민 웹(frip.host)에 더해 **호스트 전용 앱**까지 냈고, 상품 등록·예약 관리·
판매 내역·정산 확인을 호스트가 직접 한다.

**개인도 호스트가 될 수 있다.** 사업자 등록이 없어도 되고, 문토는 개인 호스트 정산분을
사업소득으로 신고해줘서 정산 시 주민등록번호를 받는다.

⚠️ **확인 못한 것**: 호스트 신청 후 심사·승인 절차가 있는지는 두 곳 다 로그인해야 보이는
영역이라 공개 페이지에서 확인이 안 된다. 필요하면 호스트로 가입해 직접 확인해야 한다.

출처: 문토 FAQ(수수료 797번), ZDNet/여행신문 2022-03-07 프립 수수료 개편 기사,
frip.host, 프립 호스트 앱(App Store id1622775512).

### 연숲이 실제로 쓰는 방법 (직접 확인)

Apify 로 인스타 프로필을 받아 확인한 결과:

- 프로필 링크 = `https://naver.me/5RAFdqtx` → **`form.naver.com` 네이버 폼**
- 링크 제목이 그대로 **"9/5 로테이션소개팅 신청서"**
- 폼 내용은 네이버 로그인을 해야 보여서 항목까지는 확인 못 했다

**네이버 폼에는 결제 기능이 없다.** 그래서 폼으로 이름·연락처를 받고, 이후 카카오톡이나
문자로 계좌를 알려줘 입금받는 방식이다. — 이 마지막 문장은 **확인한 사실이 아니라
"네이버 폼은 결제를 못 받는다"에서 나온 추론**이다.

## 3. 우리가 업체 직접 등록 기능을 만든다면

### 결제를 우리가 받지 않는 길 (권장, 지금 단계)

지금처럼 신청하기를 누르면 업체 쪽으로 보낸다. 결제·환불·정산을 안 만들어도 된다.

- 홈페이지 있는 업체 → 상품 주소만 등록
- 홈페이지 없는 업체 → **신청 폼 주소**를 등록. 연숲처럼 이미 네이버 폼을 쓰는 곳이 많다
- 폼조차 없는 업체 → 우리가 간단한 신청 폼을 제공하고 **신청자 명단만 업체에 넘긴다**.
  여기까지는 우리에게 돈이 들어오지 않는다

### 결제를 우리가 받는 길

수수료 20%를 먹으려면 결국 여기로 와야 하지만, 붙는 일이 통째로 달라진다.

- PG 계약과 카드사 심사 — toolshere 에서 이미 겪은 문제가 그대로 반복된다
  (BC 영구 불가, 보증보험 미가입 등)
- 환불 규정·정산 시스템·세금계산서·분쟁 처리
- 남의 돈을 대신 받아 나중에 주는 구조 → 통신판매중개업 신고, 에스크로

**결론(2026-09-03 오너와 합의):** 결제는 마지막에 붙인다. 붙이는 이유는 수수료 수익이지
사용자 편의가 아니다. 지금은 업체가 자기 방식대로 받게 두고, 우리는 **신청 버튼이 몇 번
눌렸는지**를 업체에 보여주면서 제휴를 늘리는 게 순서다.

그래서 2026-09-03 에 메뉴별 계측을 심으면서 신청 클릭(`outlink_click`)과 모잇 할인 팝업
노출(`partner_notice_view`)을 업체별로 집계할 수 있게 해뒀다. 그 표가 곧 제휴 영업 자료다.

## 4. 우리가 못 보는 것

신청 버튼을 눌렀다는 것까지만 안다. **실제로 몇 명이 신청하고 결제했는지는 알 수 없다.**
문토·프립은 결제를 자기가 받으니 전환까지 다 보인다 — 그게 장터형과 모아보기형의 차이다.
